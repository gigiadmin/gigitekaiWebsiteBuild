# Mobile Device Setup & Troubleshooting Guide

**Category:** Mobile & Remote Access | **Tier:** 1 | **Resolution Time:** 15-20 minutes | **Difficulty:** Beginner

## Overview

Mobile devices (smartphones and tablets) are essential for remote work and productivity. This guide covers email setup, app installation, troubleshooting common issues, and best practices for secure mobile device management.

## Common Mobile Device Issues

| Issue | Symptom | Typical Cause |
|-------|---------|---------------|
| Cannot Access Email | Email app won't connect | Incorrect settings or wrong password |
| Slow Performance | App freezes or lags | Low storage or too many apps running |
| Battery Drains Quickly | Battery depletes rapidly | Background apps or high brightness |
| Cannot Connect to WiFi | WiFi network won't connect | Wrong password or network issue |
| App Crashes | App closes unexpectedly | Outdated app or insufficient storage |
| Cannot Install App | App installation fails | Insufficient storage or compatibility issue |
| Overheating | Device gets hot | Too many apps running or direct sunlight |
| Storage Full | Cannot install apps or take photos | Device storage is full |

## Solution Steps

### Step 1: Set Up Email on Mobile Device

**For iPhone (iOS):**

1. **Open Settings app** - Look for gear icon
2. **Tap "Mail"** - Scroll down to find it
3. **Tap "Accounts"** - Select "Add Account"
4. **Choose "Other"** - For company email
5. **Enter email address** - yourname@gigitekai.com
6. **Enter password** - Your current email password
7. **Configure settings:**
   - **Incoming Mail Server:** mail.gigitekai.com
   - **Username:** yourname@gigitekai.com
   - **Password:** Your email password
   - **Outgoing Mail Server:** mail.gigitekai.com
8. **Tap "Next"** - Proceed through setup
9. **Select "Mail"** - Choose what to sync (Mail, Contacts, Calendars)
10. **Tap "Save"** - Email account is configured

**For Android:**

1. **Open Gmail app** - Or your email client
2. **Tap "Add account"** - Usually shows + icon
3. **Select "Other"** - For company email
4. **Enter email address** - yourname@gigitekai.com
5. **Enter password** - Your current email password
6. **Configure settings:**
   - **Incoming Server:** mail.gigitekai.com (Port 993, SSL)
   - **Outgoing Server:** mail.gigitekai.com (Port 587, TLS)
   - **Username:** yourname@gigitekai.com
7. **Tap "Next"** - Complete setup
8. **Choose sync options** - Select what to sync
9. **Tap "Done"** - Email account is configured

### Step 2: Install Company Apps

To install required company applications:

**For iPhone:**
1. Open App Store
2. Search for app name (e.g., "Microsoft Teams", "Outlook")
3. Tap "Get" → "Install"
4. Use Face ID or Apple ID to confirm
5. Wait for installation to complete
6. Tap "Open" to launch app

**For Android:**
1. Open Google Play Store
2. Search for app name
3. Tap "Install"
4. Review permissions and tap "Install"
5. Wait for installation to complete
6. Tap "Open" to launch app

### Step 3: Troubleshoot Slow Performance

If your mobile device is slow:

1. **Restart device** - Power off and on again
2. **Close background apps:**
   - **iPhone:** Swipe up from bottom and swipe up on apps
   - **Android:** Recent apps button → Swipe up on apps
3. **Reduce brightness** - Lowers battery drain and heat
4. **Disable background app refresh:**
   - **iPhone:** Settings → General → Background App Refresh → Toggle OFF
   - **Android:** Settings → Apps → Select app → Battery → Background restriction
5. **Clear cache:**
   - **iPhone:** Settings → General → iPhone Storage → Select app → Offload App
   - **Android:** Settings → Apps → Select app → Storage → Clear Cache
6. **Update apps** - Outdated apps may be slow
7. **Restart device** - Final restart to apply changes

### Step 4: Manage Storage Space

If device storage is full:

1. **Check storage usage:**
   - **iPhone:** Settings → General → iPhone Storage
   - **Android:** Settings → Storage
2. **Delete unused apps:**
   - **iPhone:** Settings → General → iPhone Storage → Select app → Delete App
   - **Android:** Settings → Apps → Select app → Uninstall
3. **Clear app cache:**
   - **iPhone:** Settings → General → iPhone Storage → Select app → Offload App
   - **Android:** Settings → Apps → Select app → Storage → Clear Cache
4. **Delete old photos/videos:**
   - Open Photos app
   - Select old photos
   - Tap Delete
   - Empty Recently Deleted folder
5. **Clear browser cache:**
   - **iPhone:** Settings → Safari → Clear History and Website Data
   - **Android:** Chrome → Settings → Privacy → Clear browsing data
6. **Move photos to cloud:**
   - Use iCloud (iPhone) or Google Photos (Android)
   - Delete local copies after backup

### Step 5: Fix WiFi Connection Issues

If mobile device won't connect to WiFi:

1. **Forget and reconnect to network:**
   - **iPhone:** Settings → WiFi → Select network → Forget → Reconnect
   - **Android:** Settings → WiFi → Select network → Forget → Reconnect
2. **Restart WiFi router** - Unplug for 30 seconds, plug back in
3. **Restart mobile device** - Power off and on
4. **Check WiFi password** - Ensure correct password is entered
5. **Move closer to router** - Improve signal strength
6. **Disable and re-enable WiFi:**
   - **iPhone:** Settings → WiFi → Toggle OFF, then ON
   - **Android:** Settings → WiFi → Toggle OFF, then ON
7. **Forget all networks and reconnect** - Reset WiFi settings

### Step 6: Handle App Crashes

If apps crash or freeze:

1. **Force close app:**
   - **iPhone:** Swipe up from bottom → Swipe up on app
   - **Android:** Recent apps → Swipe up on app
2. **Restart device** - Power off and on
3. **Update app:**
   - **iPhone:** App Store → Updates → Update app
   - **Android:** Google Play Store → My apps & games → Update app
4. **Clear app cache:**
   - **iPhone:** Settings → General → iPhone Storage → Select app → Offload App
   - **Android:** Settings → Apps → Select app → Storage → Clear Cache
5. **Reinstall app:**
   - Delete app
   - Restart device
   - Reinstall from app store
6. **Check storage** - Ensure sufficient free space (at least 1-2 GB)

### Step 7: Improve Battery Life

To extend battery life:

1. **Enable Low Power Mode:**
   - **iPhone:** Settings → Battery → Low Power Mode → Toggle ON
   - **Android:** Settings → Battery → Battery Saver → Toggle ON
2. **Reduce screen brightness** - Settings → Display → Brightness
3. **Disable location services:**
   - **iPhone:** Settings → Privacy → Location Services → Toggle OFF
   - **Android:** Settings → Location → Toggle OFF
4. **Disable background app refresh:**
   - **iPhone:** Settings → General → Background App Refresh
   - **Android:** Settings → Apps → Select app → Battery
5. **Close unused apps** - Reduce number of running apps
6. **Disable notifications** - Settings → Notifications → Disable unnecessary
7. **Turn off Bluetooth when not needed** - Settings → Bluetooth
8. **Use WiFi instead of cellular data** - WiFi uses less battery

### Step 8: Update Mobile Device

Keep your device secure and performant:

**For iPhone:**
1. Settings → General → Software Update
2. If update available, tap "Download and Install"
3. Enter passcode if prompted
4. Wait for installation (may take 30+ minutes)
5. Device will restart automatically

**For Android:**
1. Settings → System → System Update
2. If update available, tap "Download"
3. Wait for download to complete
4. Tap "Install"
5. Device will restart automatically

### Step 9: Troubleshoot Email Sync Issues

If emails aren't syncing:

1. **Check internet connection** - Ensure WiFi or cellular is connected
2. **Verify email credentials** - Confirm password is correct
3. **Re-add email account:**
   - Delete email account from device
   - Restart device
   - Re-add email account
4. **Check sync settings:**
   - **iPhone:** Settings → Mail → Accounts → Select account → Sync
   - **Android:** Gmail → Settings → Account → Sync Gmail
5. **Increase sync frequency:**
   - **iPhone:** Settings → Mail → Fetch New Data → Change to "Every 15 minutes"
   - **Android:** Gmail → Settings → Data usage → Sync Gmail
6. **Clear email app cache:**
   - **iPhone:** Settings → General → iPhone Storage → Mail → Offload App
   - **Android:** Settings → Apps → Gmail → Storage → Clear Cache

### Step 10: Enable Security Features

Protect your mobile device:

1. **Set up passcode/PIN:**
   - **iPhone:** Settings → Face ID & Passcode
   - **Android:** Settings → Security → Screen lock
2. **Enable biometric authentication:**
   - **iPhone:** Face ID or Touch ID
   - **Android:** Fingerprint or Face Unlock
3. **Enable automatic lock:**
   - **iPhone:** Settings → Display & Brightness → Auto-Lock → 1 minute
   - **Android:** Settings → Security → Screen timeout → 1 minute
4. **Install security app:**
   - **iPhone:** Built-in security; no additional app needed
   - **Android:** Install McAfee Mobile Security or similar
5. **Enable Find My Device:**
   - **iPhone:** Settings → [Your Name] → Find My
   - **Android:** Settings → Google → Manage your Google Account → Security
6. **Keep apps updated** - Enable automatic updates in app store

## When to Escalate

Contact your IT support team if:

- Email won't sync despite troubleshooting
- Device won't connect to company WiFi
- You need to enroll device in Mobile Device Management (MDM)
- Device is lost or stolen
- You need VPN setup on mobile device
- You need help installing company apps
- Device has security concerns or suspected malware

## Security Best Practices

**Protect Your Mobile Device:**
- Use strong passcode (6+ digits or longer)
- Enable biometric authentication (Face ID, fingerprint)
- Keep device updated to latest OS version
- Only install apps from official app stores
- Don't jailbreak (iPhone) or root (Android) your device
- Avoid public WiFi for sensitive activities
- Use VPN on public WiFi if available
- Enable automatic lock (1 minute)
- Review app permissions before installing
- Don't share device with others

**Maintain Privacy:**
- Disable location services when not needed
- Review privacy settings in apps
- Don't save passwords in browser
- Use password manager for credentials
- Clear browser cache regularly
- Disable Bluetooth when not in use
- Be cautious of phishing emails
- Report suspicious activity to IT

## FAQ

**Q: Can I use my personal phone for work?**
A: Check with IT. Some companies allow BYOD (Bring Your Own Device), others require company-issued devices.

**Q: How do I back up my mobile device?**
A: **iPhone:** iCloud (Settings → [Your Name] → iCloud) | **Android:** Google Account (Settings → Accounts)

**Q: Is it safe to use public WiFi on mobile?**
A: Not recommended. Use VPN if available. Avoid accessing sensitive information on public WiFi.

**Q: How often should I restart my mobile device?**
A: Weekly restart is recommended to maintain performance and security.

**Q: Can I install apps from sources other than app stores?**
A: Not recommended. Only install from official App Store (iPhone) or Google Play Store (Android).

**Q: What should I do if my device is lost or stolen?**
A: Contact IT immediately. They can remotely wipe the device to protect company data.
