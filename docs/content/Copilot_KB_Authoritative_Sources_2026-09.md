# Microsoft Copilot KB Authoritative Source Notes

These official sources were used to define and validate the September 2026 GigitekAI Microsoft Copilot Knowledge Base expansion.

## Microsoft Copilot documentation hub

- Source: https://learn.microsoft.com/en-us/microsoft-365/copilot/
- The hub organizes guidance for planning, implementing, managing, securing, governing, adopting, and extending Microsoft Copilot.
- Extensibility areas include Microsoft 365 Copilot connectors, agents, APIs, and Microsoft Copilot Studio.

## Microsoft Copilot overview

- Source: https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview
- Current documented experiences include Copilot Chat (Basic), Microsoft 365 Copilot (Basic), and Microsoft 365 Copilot (Premium).
- Responses can be grounded in public web data and, depending on experience and licensing, organizational data through Microsoft Graph and Work IQ.
- Work-account experiences use Enterprise Data Protection; access remains scoped by user permissions.
- The Copilot Control System provides tenant controls for pinning, image generation, agent creation/use, web search grounding, and Copilot Chat access.
- Microsoft documents an AI Administrator role for least-privilege Copilot and AI administration.
- Adoption reporting includes Copilot Chat usage and Microsoft 365 application usage reports.

## Microsoft Copilot Studio documentation

- Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/
- Documented capabilities include agent and workflow creation, knowledge and tool integration, agent evaluation, activity trace, conversation history, authentication, data policies, analytics, publishing, and lifecycle management.
- Publishing targets include SharePoint, websites, Teams, and Microsoft 365 Copilot.
- Microsoft documents both standard and GitHub Copilot harnesses; feature availability can vary by tenant, licensing, region, and release status.

## Microsoft Copilot Chat documentation

- Source: https://learn.microsoft.com/en-us/copilot/microsoft-copilot
- The documentation covers Copilot Chat overview, privacy and protections, management, agents, Edge integration, and frequently asked questions.

## Responsible AI and human review

- Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/azure-openai-human-review
- Microsoft identifies fabrication or hallucination as a generative-AI risk and recommends human review for consequential automation and generated output.
- Source: https://www.microsoft.com/en-us/ai/responsible-ai
- Microsoft’s responsible-AI guidance emphasizes human-centered design, reliability, safety, privacy, security, transparency, fairness, and accountability.
