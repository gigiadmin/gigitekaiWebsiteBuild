- Hero: Full-width dark with animated particle/grid overlay, large left-anchored headline
- Services: Horizontal scrolling card strip on mobile, 2x2 grid on desktop

- Alternating sections: dark/light/dark rhythm matching reference site

**Signature Elements:**
1. Glowing cyan border-left on section labels (replaces green underline from reference)
2. Hexagonal icon containers for service cards
3. Animated gradient mesh in hero background

**Interaction Philosophy:**
- Hover states reveal cyan glow on cards
- Smooth scroll with section fade-in animations
- CTA buttons have subtle pulse animation

**Animation:**
- Hero: Floating particle network animation
- Cards: Staggered entrance from bottom on scroll
- Stats: Count-up animation when in viewport
- Nav: Blur-glass effect on scroll

**Typography System:**
- Display: Space Grotesk Bold (700) — geometric, technical authority
- Body: Inter Regular (400) — clean readability
